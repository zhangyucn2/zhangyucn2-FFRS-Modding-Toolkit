# 外部工具来源说明（third-party tools）

本目录里的程序**大多不是本项目原创**，仅用于调用/打包游戏数据。
本项目不主张对它们的任何权利；转发或再分发前请先确认各自的许可。

## 工具清单

| 文件 | 来源 | 用途 |
|---|---|---|
| `retoc.exe` | retoc（trumank）<https://github.com/trumank/retoc> | IoStore 容器（`.utoc/.ucas`）读写：`to-legacy` / `to-zen` / `unpack-raw` / `pack-raw` |
| `repak.exe` | repak（trumank）<https://github.com/trumank/repak> | `.pak` 读写；生成空 `_P.pak` |
| `UAssetGUI/UAssetGUI.exe` | UAssetGUI（atenfyr）<https://github.com/atenfyr/UAssetGUI> | uasset ↔ JSON（本工具链已主要改用 ffr-dt） |
| `ffr-dt/` | FFR Vision Studio <https://github.com/FFBE-JP-Translation/FFR-Vison-Studio><br>源码 `mod-tools/src/ffr-dt/` | DataTable 读取/改写、演出克隆（`patch` / `tojson` / `fromjson`）<br>构建与运行时要求见 `BUILD_说明.md` |
| `ffr-dt/UAssetAPI.dll` | UAssetAPI（atenfyr）<https://github.com/atenfyr/UAssetAPI><br>本目录为 **1.1.0.0**（随 ffr-dt 一起分发） | UE 资产（uasset/uexp）读写库；ffr-dt 的核心依赖，UAssetGUI 也基于它 |
| `ffmpeg.exe` | FFmpeg <https://ffmpeg.org/> | 视频编码（USM 替换的 VP9 / alpha） |
| `cricodecs.exe` | 社区提供的工具（随包分发时请保留其原始出处/说明） | CRIWARE（USM / HCA）解码与编码 |
| `oo2core_9_win64.dll` | Oodle（RAD Game Tools） | Oodle 解压（retoc / repak 依赖），注意授权 |
| `FFRS.usmap` | 从本游戏（UE 5.6）生成的映射文件 | 供 UAssetAPI / ffr-dt 解析；**不是可执行工具**，首页有单独路径设置 |

> **UAssetAPI** 是库而不是可执行文件，随 `ffr-dt/` 一起加载（`UAssetAPI.dll`，版本 1.1.0.0）。不要单独抽走或单独转发；升级 ffr-dt 时随其一起更新，许可见源仓库。

## 注意

- 本项目只是调用这些工具，不对其行为与许可负责。
- 对外分发整套工具前，请逐个确认许可；不确定的建议**只提供出处链接**，让对方自行下载。
- **ffr-dt 请勿单独转发二进制**，出处与构建方法见 `ffr-dt/BUILD_说明.md`。
