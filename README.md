# 最终幻想共鸣模组制作工具使用说明

> 启动：双击 `启动 Toolkit.bat`，或运行 `python FFRS_Toolkit.py`。

> English manual: [FFRS_Modding_Toolkit_Manual_EN.md](FFRS_Modding_Toolkit_Manual_EN.md)


# 准备：

1. 安装python及相关依赖，推荐py3.14，其他版本待验证，详细说明见/Python环境说明.md

2. 下载外部工具并放到/tools或对应子目录下，详见/tools/外部工具来源.md

3. ffr-dt.exe需要自行编译，方法详见/tools/ffr-dt/BUILD_说明.md

4. 音频 key：公开版不内置。运行 `python/FFRS_AudioKeyTool.py`，选择游戏根目录即可自动获取并写入 `tools/criwarekey.txt`；也可以手动把 key 写入该文件（模板见 `tools/criwarekey.example.txt`）。仅音频解码/编码需要 key，视频、技能、精灵片功能不受影响。



# 使用说明：

## 精灵片解析还原工具：

1. 角色资源：将解包的精灵片和对应的uasset/uexp（精灵片可以用Fmodel解包获取，uasset/uexp需要用retoc -legacy获取）放入导入目录下/char，点击扫描检索可编辑角色，从下来菜单中选中需要导出/预览/还原的角色；

2. 解析/刷新预览：解析选中角色的动画和对应切片将结果显示在动画预览窗口，切换角色再次点击即可刷新预览；

3. 导出当前动画PSD：将精灵片导出为分层的PSD，复用的切片不会重复导出，且优先完整导出待机动作第一帧调用的切片；

标准=预览效果

safe 1px=预览效果外加1像素的黑色安全框，切片编辑后不出框，后续还原精灵片必定不会出问题（坐标定位已左上角为原点，所以切片像右下扩展可能也没问题，欢迎勇敢尝试：）

编号版=预览效果+切片编号，编号=PSD图层名的cell编号（工具中所有显示cell编号都是统一的，方便定位修改哪个切片）

4. 导出当前帧PSD：将预览中的当前帧导出为分层PSD；

5. 导出当前角色资源PSD：相当于将PSD的图层导出为切片PNG，早期功能，不建议用；

6. 导出切片：不过PSD直接导出切片PNG，早期功能，不建议用；

7. 检查PSD图层：检查修改后的PSD图层是否合规（命名/重复等等），下方日志有概述，导出目录中有报告；

8. 对比PSD图层：检查出问题但还是不知道问题在哪可以试试这个功能，对比修改后PSD和导出的PSD，日志/报告方式同上；

9. 前所切片动画索引：填入编号，可以看到该切片被哪些动画调用，后期微调效果或者解绑动作和切片时常用功能；

10. 解除切片动画引用：原版角色和替换后角色的设计必然存在差异，可以用这个功能解除某个切片和动画的绑定关系（也就是这个动画播放时，不在显示该切片），可以解除和整条动作的绑定也可以按帧数解除局部绑定（比如0\-10帧不显示，11帧之后还能正常显示）

注意：我只做了解绑功能，没有绑回，记得常备份！！！

11. 编辑动画帧：还是因为角色修改前后的差异，为了确保不出安全框的安全还原精灵片，一些动作的某些帧可能会很奇怪，那么可以用这个功能逐帧微调，在预览中拖动滑条到需要修改的关键帧，点击编辑动画帧，在弹出的新窗口中点击需要调整的切片，左键拖拽或者ASDW调整位置，然后点击记录当前修改（暂存到内存，不写入uexp），关闭窗口其他选择关键帧继续修改，最后点击保存动画帧就可以一次性保存多个修改了。

注意：保存的uexp在导出目录，如果想二次修改需要替换掉导入目录中的uexp，所以还是做好备份！！（工具体会自动备份当前导入目录中的uexp，反复替换修改的话还是需要人工备份）

注意2：导出中存在当前角色的uexp时出于安全考虑无法直接保存，算是一种备份提醒

12. 原始精灵片：扫描导入目录，可从下来菜单中选择当前角色的原版精灵片，还原精灵片前置步骤；

13. 修改后的PSD：扫描导入目录，可从下来菜单中选择当前角色修改后的精灵片（理论上支持PSD/TIFF等格式，但工具默认导出为PSD，所以还原建议也用PSD）；

14. PSD导出贴图：默认all（_tex/_mreo/_normal）；

15. 从PSD还原Sprite：所有修改完成，检查/对比PSD无误，点击将分层的PSD重新还原出一张精灵片。

注意：在UE5.6完成精灵片烘焙后，记得带上修改过帧位置和索引关系的uexp/uasset（uasset其实没参与修改，打包需要，记得带上）再用retoc-zen完成打包。



## 描边贴图生成工具：

模拟FFRS的描边贴图，这个用起来很简单，将上一步还原的精灵片放回导入目录，这边扫描选中，然后生成_mreo即可。



法线贴图制作方式详见工具中的说明，要用到Nvidia Texture Tools Exporter，理论上所有支持用alpha模拟深度信息的题图转法线工具都可以，修正法线描边可以按需使用，导入生成的法线贴图可以完成像素级微差调整，实际效果不算明显。



## 终结技动画演出替换工具：

1. 解析：解析导入目录中的素材和游戏原版usm视频（用Fmodel - export raw导出usm），下方可以预览；

2. 对应选择原版视频/替换用视频和音频再点击生成MOD就可以完成终结技的演出替换；

注意：视频长度信息目前无法修改（用UE4ss也hook不到），所以替换用视频/音频需要和原视频时长一致，否则时长更短则循环播放，时长超出则中途裁切。替换视频支持 Alpha 通道（透明视频需原影片本身带 alpha）。

3. 音量：因为游戏中背景音乐会一定程度覆盖替换的音频，可以按需增大音量（默认和原版音量对齐）；

注意：祠堂中的幻兵生平动画也可以用这个工具替换；

注意2：原视频的usm中本质不包含音频，本工具会直接检索游戏目录中的资产定位对应音频并完成替换打包，所以导入的视频即便有声音也不会被读取，需要配套修改声音必须单独配音频文件；

注意3：幻兵祠堂演出台词和视频不是一一对应关系，如需同步替换，到下一个工具中处理。



## 剧情台本及语音替换工具：

1. 解析：解析角色所有相关文本

注意：本工具只检索游戏Localization中的文本，FFRS技能文本不再次列，如需修改，请在技能编辑时同步进行；

2. 导出/导入台词：将剧情台词部分的文本导出为excel表格，对应填写后可以用导入台词功能批量导回，手动输入替换音频路径也可以一次性完成导入（比如：C:\xxxx\yyy\zzz\替换音频\.wav）；

3. 解析出角色文本后可以在右侧编辑需要修改的语言，支持简繁日英，单条修改后记得Crtl+回车暂存，下方也支持搜索和批量替换（替换人名或者特定名词非常好用！），改好记得点击批量暂存；

4. 左侧文本界面中字幕对应的就是终结技动画中显示的字幕，选中对应字幕，修改文本的同时可以在时间轴输入字幕显示/结束的时间点，记得Crtl+回车暂存；

注意：影片起点默认为2.0，不建议修改，如果所有角色终结技演出动画的字幕播放逻辑一致，大概率都有这2秒的切入时间戳，只有遇到一直有时间偏差的情况下才考虑修改。

5. 所有文本折腾完点击生成MOD即可。



## 技能编辑或替换工具：

1. 读取：读取角色的技能表，目前主角/幻兵/召唤兽的技能表都可以修改；

2. 读取成功后，双击需要修改的技能进入修改界面；

3. 具体修改方式大体分为直接修改（双击进入修改界面后直接修改当前技能），替换技能（直接A替换为B），新建技能（替换时生成新ID就会进入新技能创建流程，目前只有新建技能可以更改技能名/技能描述)，详情见工具内置的使用说明（比较复杂，除了简单的替换和修改数据，还可以修改附带增益/减益，自由组合技能的攻击动作和特效，我自己也会忘，所以直接把说明内置了）；

4. 修改技能后会自动暂存，可以一次修改多个技能，然后一次性生成MOD（FFRS的技能表写法比较坑，建议一次性把需要修改的技能改好再生成MOD，否则...请换下一个工具）。

注意：生成的ID是以游戏技能表中可用的空栏第一个开始递增，除了避免替换游戏原技能，也用于MOD合并识别，建议让工具自动生成，随意手填不确定会不会出问题（感觉应该不会？）。



## 模组合并工具：

会自动识别导出中的MOD，通常只需要注意：

1. 所有非技能修改MOD用合并直接整合；

2. 所有技能修改MOD用智能合并，先扫描新技能，再整合。

注意：不建议将非技能MOD和技能MOD合并，一是因为技能修改MOD中修改的技能名/描述只有一种语言（FFRS自身问题，暂时无解，需要多语言就需要修改多次）；二是技能表有坑，导致和retoc -zen出来的MOD有结构差异，虽然现在理论上已经能正确重构再合并了，但我还是遇到过出错的情况，所以不建议强行合并，徒增分析（没有新建技能问题其实不大，但如果有新建技能很容易坑）。

3. 还是技能表的坑，多个技能修改MOD无法共存（同一个表头，MOD被读取时会相互覆盖，最后只生效一个），所以如果要用不同人制作的技能MOD，必须合并才能同时生效。如果多个MOD都有新建技能，则需要在智能合并时填写（新技能ID：动画源ID：特效源ID）（本机修改的多个技能MOD不需要手动输入，与人共享的时候可以把智能合并里扫描的新技能ID们也一并共享）。
